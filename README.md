# Geoanalytics — sitio web

Sitio editorial y comercial de **Geoanalytics E.I.R.L.**: geomarketing, inteligencia comercial, datos y mapas de Paraguay.

- Generador: [Eleventy](https://www.11ty.dev/); Alojamiento: GitHub Pages; Panel de edición: [Pages CMS](https://pagescms.org); Formulario: [Web3Forms](https://web3forms.com)
- **Guía completa de publicación y mantenimiento: [GUIA.md](GUIA.md)**

## Uso local

```bash
npm install
npm start        # vista previa en http://localhost:8080
npm run build    # compila en _site/
npm run contorno # regenera el contorno de Paraguay usado en la escena 3D (opcional)
```
